# Geometry

Проект для выполнения геометрических вычислений.

## Возможности

В проекте реализованы функции для:

- вычисления площади треугольника;
- вычисления периметра треугольника;
- вычисления площади квадрата;
- вычисления периметра квадрата.

## Функции

`triangle_area` - вычисляет площадь треугольника.

`triangle_perimetr` - вычисляет периметр треугольника.

`square_area` - вычисляет площадь квадрата.

`square_perimetr` - вычисляет периметр квадрата.

## План тестирования

### 1. Цели и задачи тестирования

Цель тестирования — проверка корректности работы функций
геометрических вычислений.

Основные задачи:

- проверка правильности вычисления площади и периметра фигур;
- проверка работы функций с целыми и дробными числами;
- проверка граничных значений;
- выявление ошибок в реализации функций.

### 2. Описание тестируемого продукта

Geometry — программный модуль, написанный на языке Python
и предназначенный для вычисления площади и периметра
треугольника и квадрата.

Исходный код расположен в файле `geometry.py`.

### 3. Область тестирования

Тестированию подлежат следующие функции:

- `triangle_area(a, b)`;
- `triangle_perimetr(a, b, c)`;
- `square_area(a)`;
- `square_perimetr(a)`.

Проверка производительности, безопасности и обработки
некорректных типов данных не входит в область тестирования.

### 4. Стратегия тестирования

Для проверки программы используются два подхода:

- ручное тестирование — вычисление ожидаемых результатов
  по геометрическим формулам и сравнение с результатами
  выполнения программы;
- автоматизированное модульное тестирование — проверка
  отдельных функций с использованием библиотеки `unittest`.

Для каждой функции предусмотрено три тестовых случая.

Автоматизированные тесты расположены в файле
`test_geometry.py` и реализованы в классе
`GeometryTestCase`, наследуемом от `unittest.TestCase`.

Для сравнения полученных и ожидаемых значений
используется метод `assertEqual`.

### 6. Критерии приёмки

Тестирование считается успешно завершённым при выполнении
следующих условий:

- проверены все четыре функции;
- выполнены все предусмотренные тест-кейсы;
- фактические результаты совпадают с ожидаемыми;
- отсутствуют ошибки при выполнении автоматизированных тестов.

### 7. Ожидаемые результаты

В результате тестирования должны быть подтверждены
корректность геометрических вычислений и соответствие
реализованных функций заявленной функциональности.

При обнаружении дефектов необходимо зафиксировать
условия их возникновения и результаты выполнения.

## Запуск автоматизированных тестов

Для запуска тестов необходимо выполнить команду
из корневого каталога проекта:

```bash
python -m unittest test_geometry.py -v
```
