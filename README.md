# Geometry

Проект для выполнения геометрических вычислений

## Возможности

В проекте реализованы функции для:

- вычисления площади треугольника;
- вычисления периметра треугольника;
- вычисления площади квадрата;
- вычисления периметра квадрата;

## Функции

`triangle_area` - вычисляет площадь треугольника

`triangle_perimetr` - вычисляет периметр треугольника

`square_area_` - вычисляет площадь квадрата

`square_perimetr` - вычисляет периметр квадрата
