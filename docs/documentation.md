# Geometry

Проект для выполнения геометрических вычислений для треугольника и квадарата

## Возможности

В проекте реализованы функции для:

- вычисления площади треугольника;
- вычисления периметра треугольника;
- вычисления площади квадрата;
- вычисления периметра квадрата;

## Функции `triangle_area`

Функции вычисляет площадь треугольника

```python
def triangle_area(a, b):
	return a * b / 2
```
### Пример вызова

```python
triangle_area(10, 5)

```
Результат:
``` text
25
```

## Функции `triangle_perimetr`

Функции вычисляет периметр треугольника

```python
def triangle_perimetr(a, b, c):
	return a + b + c
```
### Пример вызова

```python
triangle_perimetr(3, 4, 5)

```
Результат:
``` text
12
```

## Функции `square_area`
вычисляет площадь квадрата

```python
def square_area(a):

```
### Пример вызова
